   drop seed == 42                                              -> +  0 run(s),  0 of them ablated
   drop not tagged BUG / not an unregularised commit            -> +  4 run(s),  1 of them ablated
   drop held-out eval (created >= 2026-08-20)                   -> +  0 run(s),  0 of them ablated

   Only the ablated column can change the swept arms, and it is zero for every gate. The
   non-ablated entrants would land in the reference conditions, whose spread is already
   under 0.7 %, and most of them cannot be used anyway: dropping the date gate admits
   runs whose eval/* is the train split, and dropping the network_class gate admits
   RodentForwardModel runs, which never recorded that field either.
