Verdict
  `reference_root` does what its name says, for the *body* targets: they stop depending
  on the walker's root pose (270 of the 640 task_obs numbers). It changes nothing about
  `root` and `quat` (35 numbers), which are the reference root pose expressed relative to
  the CURRENT root in both settings -- an undelayed root position and orientation error, as
  the identity check on each block's last line confirms. Neither setting lets the joint
  configuration into task_obs, which is what `absolute` buys and what makes the delay
  experiment meaningful at all.

  So a `dec_use_proprioception=False` run has no joint-level feedback and no delayed input
  of any kind, but it does see, fresh every step, how far and how wrongly-oriented its root
  is relative to the reference -- exactly the two quantities that terminate the episode
  (`root_too_far` at 0.1 m, `root_too_rotated` at 60 deg).
